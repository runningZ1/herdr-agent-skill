# Herdr 全部核心源码审查

已审查并修订7个活跃Python源码文件：scripts/herdr_agent.py、scripts/doctor.py、tests/test_adapter.py、tests/e2e.py、tools/validate.py、tools/build.py、tools/collect.py。适配入口升至1.0.1，仍使用官方Herdr TUI 0.9.5。

源码、测试、设计、证据、schema和发行包全部位于本技能目录；server-manager/tasks/herdr-skill仅留progress.md，不再是运行或构建依赖。迁移前后逐文件SHA-256核对。5个旧一次性脚本以development/history/*.py.txt归档，避免import或误运行产生动作。

## 发现与修复

| 级别 | 问题 | 修复与证据 |
|---|---|---|
| P1 | ID只接受数字，真实Herdr返回wA后无法继续操作或清理 | 允许字母数字句柄；回归覆盖wA/wA:tB/wA:pC，真实wB流程通过 |
| P1 | close将缺失collection当空列表，可能误报关闭成功 | 严格检查集合及每项ID；无效结构返回BACKEND_PROTOCOL、unknown |
| P2 | create/split/start校验不足，rename只返回accepted | 二次get核对ID、label、name、kind、pane及严格布尔就绪；rename返回confirmed=true |
| P2 | stdin和继承输出管道可能无界阻塞 | stdin按平台轮询且有deadline，拒绝交互输入；子进程生命周期和EOF排水均有deadline |
| P2 | 无效输入在连接后端后才被发现，重复JSON键/NaN等处理不清 | 在后端前验证，拒绝空JSON、重复键、非有限常量、孤立代理字符和无效标志 |
| P2 | 创建预演不验证运行中会话；调用者移动后保护不完整 | 每次写规划查询live caller，关闭计划绑定拓扑，预演列出影响对象和脱敏变更 |
| P2 | doctor的JSON字符串未按结构脱敏，截断可能先于脱敏 | 共享核心执行界限，解析JSON后脱敏再截断，增加常见secret键和canary测试 |
| P2 | 测试写死用户名、历史w7和实时列表数量 | 相对路径、隔离FixtureBackend；真实E2E需--run，默认不启动模型 |
| P2 | 构建依赖外部Skill路径，全目录压缩可能发布原始屏幕证据 | 内置标准库validate/build/collect，白名单打包；排除本机证据、旧源码、sources和缓存 |
